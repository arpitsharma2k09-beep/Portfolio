Portfolio

A personal portfolio website for Arpit Sharma, a first-year B.Tech Computer Science student at KIET Deemed to be University. The design is inspired by a vintage library card catalog, with paper-toned cards, typewriter headings and a "catalog drawer" header.

Live site: https://arpitsharma2k09-beep.github.io/portfolio/

Sections
About: a short introduction with a photo card
Skills: HTML & CSS, Python, C/C++ and prompting, each with a level tag
Projects: Snakes and Ladder (a terminal game in Python) and a Bank Management System (Python and MySQL)
Resume: a download button for the PDF resume
Contact: email and links to GitHub and LinkedIn
Tech stack

HTML5 · CSS3 · a small piece of vanilla JavaScript (the footer year) · Google Fonts (Special Elite, IBM Plex Serif, IBM Plex Mono)

No frameworks and no build step.

How to run
Download or clone this repository.
Open portfolio.html (or index.html) in any modern browser.
Project structure
portfolio/
├── index.html        # the whole site (HTML, CSS and JS in one file)
├── images/           # profile photo and project screenshots
└── Resume_Arpit_Sharma.pdf
Design notes
Colour palette: aged paper, navy ink, rust-red stamp and teal accents
Responsive layout that collapses to a single column on small screens
Smooth scrolling, with animation turned off for users who prefer reduced motion
